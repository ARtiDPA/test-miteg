# Отчёт по продажам

Скрипт считает количество заказов и выручку по каждому товару за каждый день.

## Как запустить

Нужен Python 3, дополнительные библиотеки устанавливать не нужно. В папке со скриптом и файлом `sales.csv` выполните:

```bash
python daily_by_sku.py
```

Результат появится в этой же папке в файле `daily_by_sku.csv`. При повторном запуске файл перезапишется.

## Проверка

Отдельно посчитали общее количество уникальных заказов и выручку по исходному файлу и сравнили с суммами в отчёте. Получилось 13 798 заказов и 10 276 540 рублей выручки. В отчёте 631 строка.

## Проблемы в данных

- Нашли 60 повторных строк. Каждый заказ учитывается один раз.
- Статусы отличаются регистром, пробелами и написанием `canceled` / `cancelled`. Скрипт приводит их к одному виду.
- У четырёх отменённых заказов не указано количество. Они входят в число заказов, но не в выручку, поэтому количество для них не требуется.
- Если данные одного заказа противоречат друг другу или у выкупленного заказа нет количества или цены, скрипт остановится с ошибкой, чтобы не выдать неверный отчёт.

## Использование ИИ

Для написания скрипта и подготовки отчёта использовался Codex. Результат проверен отдельным подсчётом итоговых заказов и выручки.
